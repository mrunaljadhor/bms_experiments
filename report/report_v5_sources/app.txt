CODE: Listing A.1: Three-tier feasibility check and leg-wise AMSA loop (backend/server.js, condensed)
function checkFeasibility(current_soc, route_distance_km, env = {}) {
  const eco_dte = calculateDTE(current_soc, 'ECO', env);
  const sport_dte = calculateDTE(current_soc, 'SPORT', env);
  let status = 'SAFE';
  if (route_distance_km > eco_dte) status = 'IMPOSSIBLE';
  else if (route_distance_km > sport_dte) status = 'CRITICAL';
  return { status, eco_dte, sport_dte,
           safety_margin_eco: eco_dte - route_distance_km,
           safety_margin_sport: sport_dte - route_distance_km };
}

// risk-aware AMSA: decide on the lower SOC bound
const decision_soc = Math.max(0, Number(current_soc) - socMargin);

for (let i = 0; i < legs.length; i++) {
  const leg_dist = legs[i].distance.value / 1000;
  const leg = checkFeasibility(simulated_soc, leg_dist, envParams);
  if (leg.status === 'IMPOSSIBLE') {
    overall_status = 'IMPOSSIBLE'; amsa_action = 'CHARGE_REQUIRED'; break;
  } else if (leg.status === 'CRITICAL') {
    overall_status = 'CRITICAL'; amsa_action = 'FORCE_ECO_MODE';
  }
  simulated_soc -= (leg_dist / leg.eco_dte) * simulated_soc;   // Eq. (4.8)
  if (chargeAtStops && i < legs.length - 1) simulated_soc = 100;
}

## Appendix C: Extended Results
H3: C.1 Federated learning on the field data
Table C.1 lists the leave-one-client-out results of federated learning with the six stand-test sessions as clients. All methods start from the synthetic-pretrained model; FedAvg uses 10 rounds of one local epoch.
TABLE: Table C.1: Federated learning on the field data (MAE, % SOC)
Held-out client | Zero-shot | Local-only (mean) | Centralized | FedAvg
S1 Single-ECO | 5.06 | 1.94 | 0.67 | 0.95
S2 Single-SPORT | 10.57 | 1.82 | 1.63 | 1.15
S3 Series-ECO | 5.53 | 1.68 | 0.60 | 0.51
S4 Series-SPORT | 8.01 | 2.46 | 1.32 | 1.80
S5 Parallel-ECO | 4.68 | 1.40 | 0.62 | 0.62
S6 Parallel-SPORT | 10.10 | 4.24 | 3.34 | 4.90
Weighted mean | 7.37 | 2.27 | 1.38 | 1.67

The float32 model is 116.6 KB; ten rounds with five clients transfer 11.7 MB, against 21.7 KB for uploading the raw stand-test data. Federated learning would save bandwidth only when each vehicle logs more than about 4.1 hours of 1 Hz telemetry per round. On CALCE (14 cell × temperature clients), FedAvg reached 8.99 % MAE against 3.17 % for centralized and 16.39 % for local-only training, with 32–38 MB of model updates against about 3.1 MB of raw data.
H3: C.2 Route-study repeatability
The route study was run three times: on 16 October 2026 at 11:49 IST (reported in Chapter 5), on 18 October 2026 at 18:37 IST and on 21 October 2026 at 08:54 IST. On the hill routes the ECO range differed by at most 0.8 km and the SOC thresholds by at most 1 percentage point between runs, and Siliguri → Darjeeling remained infeasible from a full charge in every run.

## Appendix H: Safety Norms Followed
- The vehicle was tested only on a stand with the rear wheel lifted and the vehicle secured; no rider was on the vehicle during the tests.
- The pack temperature stayed between 30 and 31 °C, and no cell was charged or discharged outside the limits of its BMS.
- Bench tests on the single cell used the protection logic of the development kit and a fixed resistor load.
- API keys are stored in environment variables and are not committed to the code repositories.
- The backend does not keep a database of trips; route requests are answered and not stored.
